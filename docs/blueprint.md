# **App Name**: WiFi Cam Stream

## Core Features:

- Camera Connection: Allow the user to connect to a WiFi camera using its IP address.
- Live Feed Display: Display the live video feed from the connected camera.
- Video Recording: Record video segments and save them locally as a history.
- History View: Display a list of recorded video segments with previews.
- Web Server: Serve the live video feed and history as a web page.

## Style Guidelines:

- Primary color: Dark gray (#333) for a professional look.
- Secondary color: Light gray (#f0f0f0) for backgrounds.
- Accent: Teal (#008080) for interactive elements.
- Clean and minimal layout with a focus on the video feed.
- Simple, clear icons for controls like start/stop recording and accessing history.
- Subtle transitions for UI elements, such as the history list.

## Original User Request:
I want an app that runs in an android phone and shares live images and history of a video camera connected to the phones WiFi hotspot. I want to access the content via web
